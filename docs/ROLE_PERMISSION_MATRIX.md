# Institute permissions

| Role | Core workspace access |
| --- | --- |
| Owner | Institute setup, membership, academics, attendance, assessments, announcements, reports, and subscription. |
| Coaching admin | Membership and academic operations; cannot manage the subscription or change an owner record. |
| Academic coordinator | Academic operations, attendance, assessments, announcements, and reports. |
| Teacher | Assigned batches and students, teaching materials and assignments, owned assessments, and assigned attendance. |
| Student | Enrolled learning activities and assessments, own submissions and attendance, and released results. |
| Platform admin | Separate platform operations through the server allowlist. |

Parent and accountant roles remain in the shared schema. Their portal workflows are outside the [V1 product scope](PRODUCT_SCOPE.md).
